Global Weather Dashboard

In Tutorial 1, you published the global_weather_2023.sdml dataset. Now, let's visualize the temperature trends using a dynamic city filter.

1 Open the Editor

Click the New Galyleo Dashboard Icon in the Launcher.

2 Verify Data (Optional)

Click on "Tables" in the right sidebar to confirm global_weather_tutorial is loaded.

3 Create the Filter

Click on "Filters" in the right sidebar and select "Add Filter".

In the dialog, configure the following:

  • Name: CityChooser
  • Type: Dropdown
  • Table: global_weather_tutorial
  • Column: CITY
